# 🍓 Fruitfolio

A modern, responsive, and visually vibrant web showcase dedicated to fresh fruits—featuring interactive browsing, nutritional highlights, and clean UI design.

## ✨ Features
- **Interactive Fruit Showcase:** Browse a curated collection of fruits with crisp visuals and detailed descriptions.
- **Nutritional Breakdown:** Quick-view cards highlighting key vitamins, health benefits, and seasonal availability.
- **Search & Filter:** Easily filter fruits by category (e.g., Citrus, Berries, Tropical) or search by name.
- **Responsive Design:** Fully optimized for seamless viewing across desktop, tablet, and mobile screens.

## 🛠️ Technologies Used
- **HTML5** – Semantic page structure
- **CSS3** – Custom styling, Flexbox/Grid layouts, and smooth hover animations
- **JavaScript (ES6)** – Interactive filtering, search functionality, and dynamic DOM rendering
